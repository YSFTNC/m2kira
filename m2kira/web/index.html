GitHub'a bağlan

İlanları görmek ve filtrelemek için gerekmez. Ayarları kaydetmek, tarama başlatmak, favori ve gizlediklerini cihazlar arasında eşitlemek için bu tarayıcıya bir kez bir GitHub anahtarı tanıtılır. Anahtar yalnız bu tarayıcıda saklanır ve yalnızca m2kira reposuna yazabilir.

  1. Yeni anahtar oluştur sayfasını aç.
  2. Ad: m2kira-site, süre: 90 gün.
  3. Repository access → Only select repositories → m2kira.
  4. Permissions → Contents: Read and write, Actions: Read and write.
  5. Generate token → çıkan anahtarı aşağı yapıştır.
